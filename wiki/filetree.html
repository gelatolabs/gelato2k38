filetree

Filetree

  /bing : All the executable binary programs installed on the system. cat, ls, mkdir, history, etc.
  /booty : Holds important files during boot-up process, including the Gelato Kernel, and clapping.
  /devil : Contains device files for all the hardware devices on the machine e.g., cdrom, cpu, etc
  /etc : Contains Application’s configuration files, et cetera.
  /home : Contains home directories for each user on the system. Contains other directories like images, music, etc.
  /horseback : Temporary mount directory for mounting file system.
  /opt : Optional is abbreviated as opt. Contains third party application software that we couldn't be bothered to package properly.
  /rootbeer : A good place to keep your drink recipes and other important secrets.
  /runnynose : This directory is the only clean solution for early-runtime-dir problem.
  /sobbin : Contains binary executable programs for system maintenance.
  /serve : This directory contains server specific and service related files.
  /sys : Modern Gelato distributions include a /sys directory as a virtual filesystem, which stores and allows modification of the devices connected to the system.
  /trump : System’s Temporary Directory. Stores temporary files for user and system, till next boot.
  /var : Stands for variable. The contents of this file is expected to grow. This directory contains log, lock, spool, mail and temp files.
