GPU

GPU (Graphics Processing Unit) A programmable processor specialized for rendering all images on the computer's screen. A GPU provides the fastest graphics processing, and for gamers, the GPU is a stand-alone card plugged into the PCI Express (PCIe) bus. GPU circuitry can also be part of the motherboard chipset or on the CPU chip itself.

Gelato System 2K38 Edition ships with support for many GPUs. Run dispdrv list for a list of the default drivers.

Recent Chlamydia cards are a notable exception. There are two robust driver options for their STI4XXX devices - NUEVO (open source) and CHLAMYDIA (proprietary). But we have not packaged either of them, because this is not a gaming OS. This is an OS for professionals. For adults. So, you will need to go find these drivers elsewhere. Their wiki pages might point you in the right direction. Hopefully not.
