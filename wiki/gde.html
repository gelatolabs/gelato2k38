Gelato Desktop Environment

The premier graphical user interface for the Gelato System.

Prerequisites

Before you can start GDE, you'll need to make sure you've loaded an appropriate display driver using 'dispdrv'.

For audio support, we recommend FalseAudio. This should work out of the box for most hardware configurations, but may require some troubleshooting if not. Remember the check the forums for help!

Usage

Just run 'gde'!

GDE doesn't support SystemG autostart so you'll need to run this manually at every boot to get to your desktop.

Troubleshooting

My desktop is tiny / blurry / all fucked up!!

You've probably loaded a display driver that isn't a perfect match for your hardware. Try another?

If you're running a recent Chlamydia system, you may need to install 3rd-party drivers. See: GPU.

Where's my start menu?

Sometimes the menu fails to populate automatically. If you're getting 404 errors, try running the initialization routine manually: 

gde initialize_startmenu

Tips

Extra apps

You can enable extra 3rd-party GDE apps by running: 

gde enable_extras

To disable them again, run: 

gde disable_extras
